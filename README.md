# NX421 Mini-Project 1 — HCP Language fMRI

This repository contains our analysis of the HCP Language task fMRI data for NX421 Mini-Project 1.

We worked with one subject and one Language LR functional run. Part 1 covers structural and functional preprocessing followed by a first-level GLM. For Part 2, our assigned variant is spatial Independent Component Analysis (ICA).

## Project notebooks

The analysis is organized into four notebooks, which should be run in order:

1. `01_structural_preprocessing.ipynb` — Skull stripping with BET, tissue segmentation with FAST, and anatomical registration to MNI space using FLIRT and ANTs SyN.
2. `02_functional_preprocessing.ipynb` — Motion correction with MCFLIRT, framewise displacement, Gaussian smoothing, and functional–anatomical alignment checks.
3. `03_glm.ipynb` — GLM design matrix, task contrasts, FDR correction, and anatomical and functional-network interpretation.
4. `04_ica.ipynb` — Spatial ICA, component-number selection, spatial maps, and correlations between ICA timecourses and GLM regressors.

## Data and environment

The analysis was performed in Neurodesk using Python, FSL, ANTs and Nilearn.

The input MRI data are stored locally under `data/` and are not included in the Git repository. Intermediate results, NIfTI images and generated figures are saved in `outputs/`.

The notebooks use project-relative paths and should be executed in numerical order. Later notebooks depend on files generated by earlier ones.

## Main analysis choices

For functional preprocessing, all 316 volumes were retained, motion correction was applied, and the images were smoothed using a 6 mm FWHM Gaussian kernel.

The GLM includes Story, Math and Cue regressors, motion-related confounds and temporal drift regressors. We use FDR correction (q = 0.05) for voxel-wise statistical inference.

For spatial ICA, slow temporal drifts were removed before PCA. We compared several model orders and retained 15 PCA dimensions and 15 ICA components based on convergence and spatial stability. The first ten ICA timecourses were compared with the GLM regressors.

## Limitations

This is a single-subject, single-run analysis. The results describe patterns observed in the available data and should not be generalized to the population without further validation.
