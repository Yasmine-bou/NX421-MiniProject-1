
# Dataset

The neuroimaging data are not included in this repository.

To run the notebooks, download the dataset
from the authorized source and place it in
the data/ directory.

Expected structure:

data/
├── README.md
├── T1/
│   └── T1w.nii.gz
└── fMRI/
    └── tfMRI_LANGUAGE_LR/
        ├── tfMRI_LANGUAGE_LR.nii.gz
        └── tfMRI_LANGUAGE_LR_task_onsets.csv

Raw neuroimaging data are excluded from GitHub
using .gitignore.
